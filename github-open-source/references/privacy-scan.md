# 开源前个人隐私扫描（"原样模式"扫并报告用）

用户要求"保持和本机原样"时，敏感清洗从"删"降级为"扫并报告"：扫一遍→命中列表成表→用户判断→批了才改本机源→再覆盖仓库副本。本报告表格式见 SKILL.md 主流程"原样模式"节。

## 两档扫描

**第一档 广谱**（发现用，误报多，只用来列候选）：邮箱 `@` 模式、手机号 `(?<!\d)1[3-9]\d{9}(?!\d)`、IPv4、密码/口令字面、`~/` 家目录引用、本机绝对路径、日期/字数等数字泛匹配。QQ 号/座机泛匹配误报率最高（会命中日期 20260924、字数 36318、日志 build 号），只当线索不当命中。

**第二档 精确**（定判用，用户特定目标词表，命中才算真敏感）：
- 用户身份：真实 QQ 号/邮箱全文（如 12345、example.com 域名）、GitHub 用户名、真实姓名/自称
- 本机环境：`/home/<user>`、`~/.ekko`、本机服务端口（如 1234）、内网 IP、P2P 组网服务名
- 本机技能库内部名：frontmatter/正文登记为 18+ 内容技能或属于用户维护的成人向技能清单、本机独有的工程线技能名——点名 = 曝光本机技能库结构与人设
- 用户个人项目：真实小说/作品名、角色名、成人向作品风格词
- 凭据：token/密码/私钥字面（`gh auth token` 输出、API key）

跑法：python re 扫文本文件（跳过 .git/ 与 .rar 等二进制），命中输出 文件:行号:标签:行内容，按文件分组列成表。

## 报告规则

- 命中表 = `| 位置 | 内容 | 级别 |`，级别分"最伤人设/环境痕迹/无"；无命中的检查项也明说"全没扫到"，不省略。
- 给 A/B/C 选项让用户选（A=只改最敏感项，B=全改，C=原样），用户选 A 时只动点名清单类命中，不改本机路径/工具名类环境痕迹。
- **绝不自动改**：报告完停手，用户判断要不要改。
- 改的位置是**本机源文件**（改完再 `cp` 覆盖仓库副本），不在仓库副本里改——副本改了下次覆盖又会带回来。

## 清单型命中修法

点名一串内部名字的命中：把名单换成**通用判据描述**（"frontmatter/正文登记为 18+ 内容技能，或属于用户维护的成人向技能清单"），保留该行判断逻辑不删整行——删整行丢掉分档作用。
